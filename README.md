# DevOps Lab

## Описание проекта

Данный репозиторий создан для выполнения лабораторной работы по дисциплине ИКТ и изучения основных инструментов DevOps.

В рамках работы я изучаю основы Git, GitHub, работу с ветками, коммитами и Pull Request.

## Контакты

GitHub: https://github.com/marylampadova23-art
## План изучения DevOps

1. Изучить основы Git и GitHub.
2. Научиться работать с ветками.
3. Изучить создание коммитов и Pull Request.
4. Познакомиться с основами CI/CD.
5. Изучить контейнеризацию и Docker.
6. Познакомиться с основами автоматизации DevOps-процессов.
